# Seismic Hazard × Building Damage Assessment / 地震ハザード情報 × 建物被害予測ツール

地震ハザードステーション（J-SHIS）の Web API を利用し、任意地点の確率論的地震ハザード曲線および地盤・サイト評価情報をブラウザ上で表示する静的 Web アプリケーションです。さらに、等価 1 質点バイリニアモデルと等価線形化法による簡易建物被害予測機能を搭載し、建物の被害確率を即座に概算できます。

**GitHub Pages:** https://takayuki-minagawa.github.io/eq-hazard-api/

---

## 概要

[地震ハザードステーション J-SHIS](https://www.j-shis.bosai.go.jp/)（国立研究開発法人 防災科学技術研究所）が公開する確率論的地震動予測地図のデータを、Web API 経由で取得し、ハザードカーブおよびサイト評価情報として可視化します。加えて、簡易建物モデルによる応答推定と被害確率算定をブラウザ上で即座に実行できます。

地図上でクリックした任意地点（または座標入力）について、以下の情報を一括取得・表示します。

### ハザードカーブ

全地震・海溝型地震（カテゴリー I+II）・直下型地震（カテゴリー III）の 3 曲線を 1 つのグラフで比較表示します。

| 曲線 | eqcode | 説明 |
|---|---|---|
| 全ての地震 | `TTL_MTTL` | 全地震源の合算 |
| 海溝型地震（I+II） | `PPE_MTTL` | 海溝型地震のうち震源断層を特定できる地震（カテゴリー I）と特定しにくい地震（カテゴリー II）の複合 |
| 直下型地震（III） | `LND_MTTL` | 活断層など陸域と海域の浅い地震（カテゴリー III） |

### 評価期間・ケースの選択

コンボボックスで以下の組み合わせを切り替えられます。選択に応じてハザードカーブ・超過確率・影響断層が全て再取得されます。

| 選択肢 | 評価期間 | 確率モデル |
|---|---|---|
| 50 年・平均ケース（デフォルト） | T50 | AVR |
| 50 年・最大ケース | T50 | MAX |
| 30 年・平均ケース | T30 | AVR |
| 30 年・最大ケース | T30 | MAX |

### 地盤・サイト評価情報

| 情報 | 内容 |
|---|---|
| **表層地盤情報** | Vs30（30 m 平均 S 波速度）、地盤増幅率（ARV）、微地形区分 |
| **地すべり地形判定** | 地すべり地形分布図との重複判定 |
| **超過確率別計測震度** | 評価期間内の超過確率に対応する計測震度（meshinfo API） |
| **超過確率（30 年）** | 30 年間で震度 5 弱〜6 強以上となる確率 |
| **影響断層一覧** | 当該地点に影響する断層の一覧（名称・発生確率・Mw・予測震度） |

### 建物被害予測

等価 1 質点バイリニアモデルと等価線形化法を用いて、ハザードカーブと建物パラメータから被害確率を算定します。

| 項目 | 内容 |
|---|---|
| **建物モデル** | 等価 1 質点バイリニアモデル（総重量 W・固有周期 T1・降伏せん断力係数 Cy・2 次剛性比 α・減衰定数 h） |
| **応答推定** | 等価線形化法（反復収束計算、告示スペクトルベース） |
| **地盤増幅** | J-SHIS の ARV（地盤増幅率）を使用し PBV → PGV 変換 |
| **被害関数** | 対数正規フラジリティカーブ × ハザードカーブの畳み込み積分 |

#### 構造種別プリセット

| 構造種別 | T1 の算定 | Cy | α | h |
|---|---|---|---|---|
| RC 低層（1-3F） | 0.037H | 0.40 | 0.01 | 0.05 |
| RC 中層（4-7F） | 0.040H | 0.30 | 0.02 | 0.05 |
| RC 高層（8F-） | 0.050H | 0.25 | 0.03 | 0.03 |
| S 造低層（1-3F） | 0.035H | 0.40 | 0.05 | 0.02 |
| S 造中高層（4F-） | 0.045H | 0.30 | 0.05 | 0.02 |
| 木造（1-3F） | 0.060H | 0.40 | 0.10 | 0.05 |

*H: 建物高さ [m]（= 階数 × 階高）*

#### 被害レベル定義（最大層間変形角 IDR）

| レベル | IDR 閾値 | 説明 |
|---|---|---|
| D1 軽微 | 1/200 (0.005) | ひび割れ発生、軽微な補修で復旧可能 |
| D2 小破 | 1/120 (0.0083) | 部材損傷、補修で使用可能 |
| D3 中破 | 1/60 (0.017) | 大きな残留変形、大規模補修必要 |
| D4 大破 | 1/30 (0.033) | 倒壊の危険性、建替え検討 |
| D5 倒壊 | 1/15 (0.067) | 倒壊または倒壊に近い状態 |

## 機能

- **地図による地点選択** — Leaflet 地図上のクリックで緯度・経度を取得
- **座標の直接入力** — 緯度・経度を数値入力して取得可能
- **評価条件の切替** — 評価期間（50 年 / 30 年）と確率モデル（平均 / 最大）をコンボボックスで選択
- **ハザードカーブ表示** — 全地震・海溝型・直下型の 3 曲線を対数スケールで 1 グラフに表示
- **地盤情報表示** — Vs30、地盤増幅率、微地形区分、地すべり判定
- **超過確率別計測震度** — 選択した評価期間に対応する計測震度
- **超過確率表示** — 30 年間で各震度以上となる確率
- **影響断層一覧** — 被害地震検索による断層リスト（海溝型・直下型分類付き）
- **建物モデル入力** — 6 種の構造種別プリセットから自動設定、またはカスタム入力
- **応答予測グラフ** — PGV vs 最大層間変形角（IDR）のグラフ（被害レベル境界線付き）
- **フラジリティカーブ** — 各被害レベル（D1〜D5）のフラジリティカーブ表示
- **被害確率算定** — ハザード積分による年超過確率・期間超過確率の数値表示
- **多言語対応** — 日本語（デフォルト）/ 英語の切替
- **ダーク / ライトモード** — テーマ切替（OS 設定の自動検出あり）
- **データバージョン自動検出** — ページ読込時に J-SHIS の最新データ年を自動判定
- **CSV ダウンロード**
  - **ハザードカーブ CSV** — 全地震・海溝型・直下型の超過確率データ
  - **サイト情報 CSV** — 地盤情報・超過確率・計測震度・影響断層一覧を統合出力

## 使用データ・API

| 項目 | 内容 |
|---|---|
| データ提供元 | [J-SHIS 地震ハザードステーション](https://www.j-shis.bosai.go.jp/)（防災科学技術研究所） |
| データバージョン | 自動検出（ページ読込時に最新年を判定） |
| 確率モデル | 平均ケース（AVR）/ 最大ケース（MAX）— 選択可 |
| 評価期間 | 50 年（T50）/ 30 年（T30）— 選択可 |
| 地震動指標 | 工学的基盤最大速度 PBV [cm/s]（工学的基盤面 Vs=400 m/s 相当） |
| 座標系 | WGS84（EPSG:4326） |

### 使用する API エンドポイント

本アプリケーションは以下の 5 種類の J-SHIS Web API を使用します。

#### 1. ハザードカーブ情報提供 API

```
/map/api/pshm/{version}/{case}/{eqcode}/{period}/hzcv.json?position={経度},{緯度}&epsg=4326
```

| eqcode | 対象 |
|---|---|
| `TTL_MTTL` | 全ての地震 |
| `PPE_MTTL` | 海溝型地震（カテゴリー I+II 複合） |
| `LND_MTTL` | 直下型地震（カテゴリー III） |

#### 2. 地震ハザード情報提供 API

```
/map/api/pshm/{version}/{case}/TTL_MTTL/meshinfo.geojson?position={経度},{緯度}&epsg=4326
```

超過確率別の計測震度（T50: P02/P05/P10/P39、T30: P03/P06）および 30 年間で各震度以上となる超過確率を取得します。

#### 3. 表層地盤情報提供 API

```
/map/api/sstrct/V4/meshinfo.geojson?position={経度},{緯度}&epsg=4326
```

Vs30、地盤増幅率（ARV）、微地形区分を取得します。

#### 4. 地すべり地形情報提供 API

```
/map/api/landslide/isContaining.json?position={経度},{緯度}&epsg=4326
```

250 m メッシュ単位で地すべり地形との重複を判定します。

#### 5. 被害地震検索 API

```
/map/api/fltsearch?position={経度},{緯度}&epsg=4326&mode=C&version={version}&case={case}&period=P_{period}&format=json
```

当該地点に影響する断層を、条件付超過確率に基づきランキング形式で取得します。

## ローカルでの実行方法

```bash
# リポジトリをクローン
git clone https://github.com/Takayuki-Minagawa/eq-hazard-api.git
cd eq-hazard-api

# ローカルサーバーを起動（CORS 制約回避のため）
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開いてください。

> **注意:** `file://` プロトコルで直接開いた場合、ブラウザの CORS ポリシーにより J-SHIS API へのリクエストがブロックされることがあります。ローカルサーバー経由でのアクセスを推奨します。

## 使い方

### ハザード情報の取得

1. 地図上で対象地点をクリック、または緯度・経度を入力して「取得」ボタンを押す
2. ハザードカーブ・地盤情報・影響断層が自動取得される
3. 評価期間・ケースはコンボボックスで切替可能

### 建物被害予測

1. **構造種別を選択** — プリセット（RC 低層、S 造、木造など）から選ぶとパラメータが自動設定される
2. **階数を入力** — 建物の階数に応じて周期 T1・等価高さ He・総重量 W が再計算される
3. **「被害予測を実行」ボタンを押す** — 計算はブラウザ内で即座に完了（数 100ms 以内）
4. **結果をタブで確認**
   - **応答予測** — PGV vs IDR のグラフ。各被害レベルの境界線が表示される
   - **フラジリティ** — 各被害レベル（D1 軽微〜D5 倒壊）のフラジリティカーブ
   - **被害関数** — 期間超過確率と年超過確率の数値一覧（バーグラフ付き）

#### カスタム入力

構造種別で「カスタム」を選択すると、全パラメータ（W, He, T1, Cy, α, h）を直接入力できます。保有水平耐力計算書等から得られた復元力特性をそのまま入力する場合に利用してください。

> **注意:** 本ツールは簡易的な地震リスク概算を目的としています。等価 1 質点バイリニアモデルと等価線形化法による推定であり、高次モード効果・非線形地盤増幅・パルス性地震動への適用限界があります。詳細な評価には多質点系モデルによる時刻歴応答解析が必要です。
