# Seismic Hazard Curve Viewer / 地震ハザードカーブ表示アプリ

地震ハザードステーション（J-SHIS）の Web API を利用し、任意地点の確率論的地震ハザード曲線をブラウザ上で表示する静的 Web アプリケーションです。

**GitHub Pages:** https://takayuki-minagawa.github.io/eq-hazard-api/

---

## 概要

[地震ハザードステーション J-SHIS](https://www.j-shis.bosai.go.jp/)（国立研究開発法人 防災科学技術研究所）が公開する確率論的地震動予測地図のデータを、Web API 経由で取得し、ハザードカーブとして可視化します。

地図上でクリックした任意地点（または座標入力）について、**50 年超過確率（平均ケース）** のハザードカーブを以下の 2 種類のグラフで表示します。

| グラフ | 内容 |
|---|---|
| **カテゴリ別ハザードカーブ** | 全ての地震、カテゴリー I、II、III を個別に表示 |
| **地震タイプ別ハザードカーブ** | 海溝型地震（カテゴリー I+II）と直下型地震（カテゴリー III）を比較表示 |

### 地震カテゴリの定義

| カテゴリ | 分類 | 説明 |
|---|---|---|
| カテゴリー I | 海溝型地震 | 海溝型地震のうち震源断層を特定できる地震 |
| カテゴリー II | 海溝型地震 | 海溝型地震のうち震源断層を特定しにくい地震 |
| カテゴリー III | 直下型地震 | 活断層など陸域と海域の浅い地震 |

---

## 機能

- **地図による地点選択** — Leaflet 地図上のクリックで緯度・経度を取得
- **座標の直接入力** — 緯度・経度を数値入力して取得可能
- **ハザードカーブ表示** — 対数スケールの超過確率グラフを 2 種類同時表示
- **多言語対応** — 日本語（デフォルト）/ 英語の切替
- **ダーク / ライトモード** — テーマ切替（OS 設定の自動検出あり）
- **CSV ダウンロード**
  - **取得データ CSV** — API から取得した全カテゴリの超過確率データ
  - **算定データ CSV** — 海溝型（I+II）・直下型（III）に集約したデータ

## 使用データ・API

| 項目 | 内容 |
|---|---|
| データ提供元 | [J-SHIS 地震ハザードステーション](https://www.j-shis.bosai.go.jp/)（防災科学技術研究所） |
| API | [J-SHIS Web API（ハザードカーブ）](https://www.j-shis.bosai.go.jp/api-pshm-hzcv) |
| データバージョン | Y2024（2024 年公開版） |
| 確率モデル | 平均ケース（AVR） |
| 評価期間 | 50 年超過確率（T50） |
| 地震動指標 | 工学的基盤最大速度 PBV [cm/s]（工学的基盤面 Vs=400 m/s 相当） |
| 座標系 | WGS84（EPSG:4326） |

### 使用する API エンドポイント

```
https://www.j-shis.bosai.go.jp/map/api/pshm/Y2024/AVR/{eqcode}/T50/hzcv.json
  ?position={経度},{緯度}&epsg=4326
```

| eqcode | 対象 |
|---|---|
| `TTL_MTTL` | 全ての地震 |
| `PLE_MTTL` | カテゴリー I |
| `PSE_MTTL` | カテゴリー II |
| `LND_MTTL` | カテゴリー III |
| `PPE_MTTL` | カテゴリー I+II（海溝型地震の複合） |

## ローカルでの実行方法

```bash
# リポジトリをクローン
git clone https://github.com/Takayuki-Minagawa/eq-hazard-api.git
cd eq-hazard-api

# ローカルサーバーを起動（CORS 制約回避のため）
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開いてください。

> **注意:** `file://` プロトコルで直接開いた場合、ブラウザの CORS ポリシーにより J-SHIS API へのリクエストがブロックされることがあります。ローカルサーバー経由でのアクセスを推奨します。

## CSV 出力仕様

### 取得データ CSV

API から取得した全 5 カテゴリの超過確率を、工学的基盤最大速度（PBV）の値ごとに出力します。

```
PBV[cm/s], 全地震(TTL_MTTL), カテゴリーI(PLE_MTTL), カテゴリーII(PSE_MTTL), カテゴリーIII(LND_MTTL), カテゴリーI+II(PPE_MTTL)
0,         1.000000,          1.000000,              1.000000,               1.000000,                1.000000
2,         1.000000,          ...
...
```

### 算定データ CSV

海溝型地震（カテゴリー I+II 複合）と直下型地震（カテゴリー III）の 2 系列を出力します。

```
PBV[cm/s], 海溝型地震(I+II), 直下型地震(III)
0,         1.000000,          1.000000
2,         ...
...
```

- 文字コード: UTF-8（BOM 付き）
- ファイル名例: `hazard_raw_53394611.csv`、`hazard_calc_53394611.csv`（メッシュコードを含む）
