# Seismic Hazard Curve Viewer / 地震ハザードカーブ表示アプリ

地震ハザードステーション（J-SHIS）の Web API を利用し、任意地点の確率論的地震ハザード曲線および地盤・サイト評価情報をブラウザ上で表示する静的 Web アプリケーションです。

**GitHub Pages:** https://takayuki-minagawa.github.io/eq-hazard-api/

---

## 概要

[地震ハザードステーション J-SHIS](https://www.j-shis.bosai.go.jp/)（国立研究開発法人 防災科学技術研究所）が公開する確率論的地震動予測地図のデータを、Web API 経由で取得し、ハザードカーブおよびサイト評価情報として可視化します。

地図上でクリックした任意地点（または座標入力）について、以下の情報を一括取得・表示します。

### ハザードカーブ

**50 年超過確率（平均ケース）** のハザードカーブを 2 種類のグラフで表示します。

| グラフ | 内容 |
|---|---|
| **カテゴリ別ハザードカーブ** | 全ての地震、カテゴリー I、II、III を個別に表示 |
| **地震タイプ別ハザードカーブ** | 海溝型地震（カテゴリー I+II）と直下型地震（カテゴリー III）を比較表示 |

### 地震カテゴリの定義

| カテゴリ | 分類 | 説明 |
|---|---|---|
| カテゴリー I | 海溝型地震 | 海溝型地震のうち震源断層を特定できる地震 |
| カテゴリー II | 海溝型地震 | 海溝型地震のうち震源断層を特定しにくい地震 |
| カテゴリー III | 直下型地震 | 活断層など陸域と海域の浅い地震 |

### 地盤・サイト評価情報

| 情報 | 内容 |
|---|---|
| **表層地盤情報** | Vs30（30 m 平均 S 波速度）、地盤増幅率（ARV）、微地形区分 |
| **地すべり地形判定** | 地すべり地形分布図との重複判定 |
| **再現期間別計測震度** | 再現期間 500〜100,000 年の計測震度（ポアソン過程） |
| **超過確率** | 50 年間で震度 5 弱〜6 強以上となる確率 |
| **影響断層一覧** | 当該地点に影響する断層の一覧（名称・発生確率・Mw・予測震度） |

---

## 機能

- **地図による地点選択** — Leaflet 地図上のクリックで緯度・経度を取得
- **座標の直接入力** — 緯度・経度を数値入力して取得可能
- **ハザードカーブ表示** — 対数スケールの超過確率グラフを 2 種類同時表示
- **地盤情報表示** — Vs30、地盤増幅率、微地形区分、地すべり判定
- **再現期間別震度** — 500〜100,000 年再現期間の計測震度
- **超過確率表示** — 50 年間で各震度以上となる確率
- **影響断層一覧** — 被害地震検索による断層リスト（海溝型・直下型分類付き）
- **多言語対応** — 日本語（デフォルト）/ 英語の切替
- **ダーク / ライトモード** — テーマ切替（OS 設定の自動検出あり）
- **CSV ダウンロード**
  - **取得データ CSV** — API から取得した全カテゴリの超過確率データ
  - **算定データ CSV** — 海溝型（I+II）・直下型（III）に集約したデータ
  - **サイト情報 CSV** — 地盤情報・再現期間別震度・影響断層一覧を統合出力

## 使用データ・API

| 項目 | 内容 |
|---|---|
| データ提供元 | [J-SHIS 地震ハザードステーション](https://www.j-shis.bosai.go.jp/)（防災科学技術研究所） |
| データバージョン | Y2024（2024 年公開版） |
| 確率モデル | 平均ケース（AVR） |
| 評価期間 | 50 年超過確率（T50） |
| 地震動指標 | 工学的基盤最大速度 PBV [cm/s]（工学的基盤面 Vs=400 m/s 相当） |
| 座標系 | WGS84（EPSG:4326） |

### 使用する API エンドポイント

本アプリケーションは以下の 6 種類の J-SHIS Web API を使用します。

#### 1. ハザードカーブ情報提供 API

```
/map/api/pshm/Y2024/AVR/{eqcode}/T50/hzcv.json?position={経度},{緯度}&epsg=4326
```

| eqcode | 対象 |
|---|---|
| `TTL_MTTL` | 全ての地震 |
| `PLE_MTTL` | カテゴリー I |
| `PSE_MTTL` | カテゴリー II |
| `LND_MTTL` | カテゴリー III |
| `PPE_MTTL` | カテゴリー I+II（海溝型地震の複合） |

#### 2. 表層地盤情報提供 API

```
/map/api/sstrct/V4/meshinfo.geojson?position={経度},{緯度}&epsg=4326
```

Vs30、地盤増幅率（ARV）、微地形区分を取得します。

#### 3. 長期間平均ハザード情報提供 API

```
/map/api/avghzd/V8/meshinfo.geojson?position={経度},{緯度}&epsg=4326
```

再現期間 500〜100,000 年の計測震度を取得します。

#### 4. 地すべり地形情報提供 API

```
/map/api/landslide/isContaining.json?position={経度},{緯度}&epsg=4326
```

250 m メッシュ単位で地すべり地形との重複を判定します。

#### 5. 地震ハザード情報提供 API

```
/map/api/pshm/Y2024/AVR/TTL_MTTL/meshinfo.geojson?position={経度},{緯度}&epsg=4326
```

50 年間で各震度以上となる超過確率を取得します。

#### 6. 被害地震検索 API

```
/map/api/fltsearch?position={経度},{緯度}&epsg=4326&mode=C&version=Y2024&case=AVR&period=P_T50&format=json
```

当該地点に影響する断層を、条件付超過確率に基づきランキング形式で取得します。

## ローカルでの実行方法

```bash
# リポジトリをクローン
git clone https://github.com/Takayuki-Minagawa/eq-hazard-api.git
cd eq-hazard-api

# ローカルサーバーを起動（CORS 制約回避のため）
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開いてください。

> **注意:** `file://` プロトコルで直接開いた場合、ブラウザの CORS ポリシーにより J-SHIS API へのリクエストがブロックされることがあります。ローカルサーバー経由でのアクセスを推奨します。

## CSV 出力仕様

### 取得データ CSV

API から取得した全 5 カテゴリの超過確率を、工学的基盤最大速度（PBV）の値ごとに出力します。

```
PBV[cm/s], 全地震(TTL_MTTL), カテゴリーI(PLE_MTTL), カテゴリーII(PSE_MTTL), カテゴリーIII(LND_MTTL), カテゴリーI+II(PPE_MTTL)
0,         1.000000,          1.000000,              1.000000,               1.000000,                1.000000
2,         1.000000,          ...
```

### 算定データ CSV

海溝型地震（カテゴリー I+II 複合）と直下型地震（カテゴリー III）の 2 系列を出力します。

```
PBV[cm/s], 海溝型地震(I+II), 直下型地震(III)
0,         1.000000,          1.000000
2,         ...
```

### サイト情報 CSV

地盤情報、超過確率、再現期間別震度、影響断層一覧を統合出力します。

```
[表層地盤情報]
Vs30[m/s], 302.9
地盤増幅率(ARV), 1.27
微地形区分, 干拓地
地すべり地形, 該当なし

[超過確率（50年・全地震）]
震度閾値, 超過確率(50年)
震度5弱以上, 0.9876
...

[再現期間別 計測震度]
再現期間[年], 計測震度
500,  4.8
1000, 5.2
...

[影響断層一覧]
#, 断層名, 分類, 発生確率, Mw, 計測震度
1, 南海トラフ沿いで発生する大地震, 海溝型, 0.949, 8.2-9.1, 4.9
...
```

- 文字コード: UTF-8（BOM 付き）
- ファイル名例: `hazard_raw_53394611.csv`、`hazard_calc_53394611.csv`、`site_info_53394611.csv`
